# 长上下文推理中的 KV Cache 压缩

## 摘要

本文研究推理阶段的 KV Cache 压缩方法，目标是在显存受限时维持长上下文任务的吞吐与质量。

## 方法

我们比较三类策略：基于注意力分数的重淘汰、基于最近窗口的滑出策略、以及把淘汰掉的 KV 归并为一个摘要槽的混合策略。评价指标包括困惑度、长文检索准确率与每 token 的显存占用。

## 结果

在 32K 上下文下，混合策略把显存占用降低 41%，同时把长文检索准确率保持在原始模型的 96% 以上；纯滑出策略显存降低更多，但因为丢失早期信息导致检索准确率下降 9 个点。

## 讨论

压缩策略与任务类型强相关：以近期上下文为主的任务适合滑出，需要回溯早期证据的任务必须保留摘要槽。实践建议按任务分布选择策略，而不是全局固定一种。
