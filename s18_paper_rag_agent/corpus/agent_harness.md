# Agent Harness 的七阶段编排与证据反思

## 摘要

本文提出一种面向检索问答的七阶段 Agent 编排：Guardrails、NLU、Retrieve、Rerank、Reflect、Generate、Memory。核心主张是把「证据是否充分」从生成阶段前移为一个独立的反思阶段。

## 方法

NLU 阶段以结构化输出完成三件事：意图分类、指代消解、Query 改写。意图分为五类：事实查找、跨文档对比、全文总结、指代追问、越界请求。指代消解从上一轮记忆中取实体替换代词，无法消解时标记为待澄清而不是猜测。

Reflect 阶段检查 Top1 重排分数与命中论文数，低于阈值时先用 Top1 命中里的关键词扩充查询做二次检索，二次检索仍不达标就主动拒答，避免无依据作答。

## 结果

在自建的四轮对话集上，引入 Reflect 后证据不足子集的拒答准确率提升约 13 个点，端到端流水线成功率从 0.68 提升到 0.76。记忆压缩把最近三轮保留原文、更早的折叠为摘要，平均 token 开销下降 34%，同时把记忆一致性维持在 0.80 以上。

## 讨论

两级 PipelineTrace（Turn 级与 Stage 级）是这套编排可调试的前提：每个阶段的输入、输出、工具调用与耗时都留痕，能快速定位答案错误的来源是检索没召回、重排排错顺序，还是生成阶段越过了证据。
